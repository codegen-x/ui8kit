# AGENTS.md — codegen-x/ui8kit

Bun monorepo (bun 1.4.2). Read README.md first, then docs/specs-guide.md.

## UI8Kit 3

Primitives come from the public UI8Kit 3 toolchain, installed by the CLI, never copied by hand:

- generator and API docs of the primitives: [ui8kit/codegen](https://github.com/ui8kit/codegen) (`docs/primitives`, `docs/runtimes`)
- registry: [@ui8kit/registry](https://www.npmjs.com/package/@ui8kit/registry) 3.2.0 ([ui8kit/registry](https://github.com/ui8kit/registry))
- CLI: [ui8kit](https://www.npmjs.com/package/ui8kit) 3.2.1 ([ui8kit/cli](https://github.com/ui8kit/cli)), a root devDependency
- data contract: [@ui8kit/contract](https://www.npmjs.com/package/@ui8kit/contract) 0.2.0 ([ui8kit/contract](https://github.com/ui8kit/contract)), used by `codex:validate`

`packages/kit/<runtime>` (svelte, react, vue, solid, templ, twig, latte, jinja2) holds the 19 primitives + slot and utils, each with
`ui8kit.config.json` and `ui8kit.lock.json`. Install or refresh one runtime:

```
cd packages/kit/react
bunx ui8kit@3 init -y --framework react      # once: ui8kit.config.json, src/utils, .cursor/rules
bunx ui8kit@3 add --all                       # 19 primitives + slot from @ui8kit/registry 3.x
bunx ui8kit@3 check                           # offline: missing, modified, mixed versions
bun run kit:check                             # from the root: ui8kit check in every packages/kit/*; part of bun run check / verify
```

Never edit `packages/kit/**` by hand (`ui8kit check` fails). Status of the migration: the composition layer (organisms, blocks,
screens, host apps) is still generated by `xgen` on top of the xgen bricks from `vendor/codegen` (archived xgen, ui8kit/codegen tag
`xgen-archive-2026-10-23`); moving it onto `packages/kit` needs the recipes (variants) moved into codegen-x and the xgen emitters
rewritten for the 19 unstyled v3 primitives. Until then `xgen/` and `packages/*/ui` stay.

## Rules for agents

- Do not edit generated files: `packages/*/ui`, `apps/host-*` (header `Code generated by xgen`) and `packages/kit/**` (installed by `ui8kit`).
- Edit specs, schemas, fixtures, content, skins and `xgen/screens/src/authoring`; then `bun run build`.
- Before a commit: `bun run verify` (kit:check + skins check + xgen check + codex:validate + typecheck + test), `bun run lint:px`, `bun run audit:push`.
- Grid 8 + 4 (no half steps), colors only by tokens, icons Lucide only. See `.cursor/rules`.
- Do not copy primitives from ui8kit/codegen or the registry into the repo; install them with `bunx ui8kit@3 add`.
