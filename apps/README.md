# apps

Three host apps, all generated by `bun run build` (DO NOT EDIT anything but `xgen.app.json`):

| app | runtime | port | a screen |
|---|---|---|---|
| `host-svelte` | Svelte 5 | 5180 | `http://127.0.0.1:5180/<screen>/#/<route>` |
| `host-react` | React 19 | 5181 | `http://127.0.0.1:5181/<screen>/#/<route>` |
| `host-vue` | Vue 3 | 5182 | `http://127.0.0.1:5182/<screen>/#/<route>` |

Two hand-written apps sit next to them (not generated, not drift-checked; neither has an `xgen.app.json`):

| app | runtime | port | what |
|---|---|---|---|
| `discovery` | Svelte 5 + Three.js | 5183 | a panorama of taste screens on a sphere: `bun run dev` in `apps/discovery`; `#/screen/<id>` shows one screen live |
| `magazine` | Svelte 5 + Three.js | 5185 | the journal of a visitor's taste, served at `/magazine/` on the same origin as `/discovery/`: recommendation rows for the 10 styles picked in Discovery (`?cards=recommend`), the rotating sphere when opened without picks. See `plan/MAGAZINE.md` |

A landing, a theme or the block gallery is a screen spec in `xgen/specs/screens`, not an app.
`<screen>` is the screen id without `screen.`; `/` lists every screen. Dictionary, data, menus and runtime core: `packages/shared/app`.
